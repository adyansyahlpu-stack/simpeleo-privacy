Kebijakan Privasi SimpelEO

Terakhir diperbarui: November 2026

Aplikasi SimpelEO dikembangkan sebagai alat manajemen event dan organizer. Kami menghargai privasi pengguna aplikasi kami.

1. Informasi yang Kami Kumpulkan

Aplikasi ini dapat menggunakan layanan pihak ketiga seperti Firebase dan Google AdMob yang mungkin mengumpulkan informasi diagnostik standar, data penggunaan, dan identifier perangkat untuk keperluan analitik serta penayangan iklan.

2. Penggunaan Iklan (Google AdMob)

Kami menggunakan Google AdMob untuk menayangkan iklan. AdMob dapat menggunakan ID iklan perangkat Anda untuk mempersonalisasi iklan berdasarkan minat Anda.

3. Keamanan Data

Kami berkomitmen menjaga keamanan data Anda. Seluruh komunikasi data dengan database menggunakan protokol enkripsi yang aman.

4. Hubungi Kami

Jika ada pertanyaan mengenai Kebijakan Privasi ini, Anda dapat menghubungi pengembang melalui halaman dukungan aplikasi.
